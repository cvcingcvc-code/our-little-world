# Our Little World（我们的小世界）❄️

> **冬天很冷，幸好有你。**  
> **想把与你有关的每一个瞬间，都偷偷收藏。**

一个具有长期温存记录价值、沉浸式冬日治愈视觉体验与双人互动能力的**数字恋爱博物馆**。  
既是专属两人的浪漫礼物，也是高质量的现代化 AI 全栈 Web 应用。

---

## ❄️ 视觉与交互特色

- **冬日动漫全景沉浸**：延续二次元冬日雪景基调（雪花白、雾霾蓝、浅灰紫、暖红围巾），无千篇一律的廉价模板设计。
- **开场意境问候**：初次入站展示唯美冬日开场问候，支持一键优雅跳过。
- **漫天飘雪微粒子**：Canvas 高性能物理轻柔飘雪，支持一键启闭与节能低动效模式。
- **纯净背景音律**：基于 Web Audio API 原生合成柔美八音盒钢琴轻音乐，零跨域阻断、零外部音频丢失风险。
- **昼夜/星空主题切换**：支持“晨雪日光”与“星夜暗语”双模式自如切换。
- **移动端独立优化**：底部悬浮极简操作栏，自适应手势触控与手机拍照直传。

---

## 🌟 核心业务矩阵（10 大模块全景）

1. **冬日恋歌首页**：全屏动漫视差、相恋天/时/分/秒精确动态走动计时牌、各模块直达入口。
2. **她的可爱收藏馆**：拍立得手账式画廊、手机/电脑上传（客户端智能画质压缩）、相册分类、标签检索、照片专属故事、全屏大图预览灯箱、随机回忆盲抽。
3. **我们的美食日记**：记录三餐四季、餐厅探店、招牌菜品、星级评分、甜蜜餐桌小剧场、专属“未来想吃清单”。
4. **礼物与惊喜博物馆**：记录心动礼物、鲜花、手写信、手作心意；区分赠予方向，珍藏开箱背后的心动瞬间。
5. **我们的 100 件小事**：愿望清单管理，待奔赴 / 进行中 / 已点亮三态管理，支持打卡凭证照片与感言，完成时触发彩色撒花动效。
6. **恋爱时间轴**：自动聚合照片、美食、礼物、愿望与纪念日，汇成一条倒序流动的时光河流，支持按年份与类型筛选。
7. **专属恋爱星空（核心特色）**：轻量交互式 Canvas 银河星空，将心动回忆凝练为闪烁星辰，点击星星浮现回忆星卡，支持拖拽与缩放。
8. **恋爱成就系统**：基于真实打卡数据（天数、照片数、愿望数）动态实时计算解锁进度，拒绝虚构冒充。
9. **恋爱温暖日记**：记录日常心语、天气心境、喜欢对方的理由与悄悄话，支持私密加密保护。
10. **时光信箱（给未来的慢速情书）**：写给未来特定日期的信件；未到解封日期界面严格锁定，保护时光仪式感。
11. **双人互动乐园**：“今日想你”双向心跳计数器（粒子动效）、秘密便利贴便签墙、回忆盲盒抽卡机、约会灵感摇奖机。

## 🔒 真实数据与隐私安全机制

- **双轨访问隔离**：
  - **访客展示模式**：未登录时仅展示公开示例与脱敏内容，适合作为作品展示。
  - **专属双人模式**：输入专属口令（默认：`love2024`）后解锁，拥有全部私密回忆的查看与增删改权限。
- **照片安全与零泄露**：
  - 本地上传的照片由客户端安全处理并保存在用户专属存储中。
  - `.gitignore` 严密屏蔽真实照片路径与环境变量，**物理杜绝任何私人真实照片被提交至 GitHub**。

## 🛠️ 技术选型与规范

- **框架**：Next.js 16 (App Router, Turbopack) + React 19
- **开发语言**：TypeScript
- **样式方案**：Tailwind CSS 4
- **动效引擎**：Canvas 物理飘雪粒子 + Canvas 动态星空 + canvas-confetti
- **音频引擎**：Web Audio API
- **图标系统**：Lucide React
- **部署平台**：Vercel CI/CD 自动部署

## 🌐 Vercel 持续自动化部署指南

1. 进入 [Vercel 控制台](https://vercel.com)。
2. 点击 **Add New...** -> **Project**，选择已绑定的 GitHub 仓库 `cvcingcvc-code/our-little-world`。
3. 在 **Environment Variables** 添加专属访问密码（可选，不填默认使用 `love2024`）：
   - `NEXT_PUBLIC_SITE_PASSCODE` = `你的专属暗号`
4. 点击 **Deploy** 按钮。
5. 后续向 `main` 分支提交推送代码时，Vercel 将全自动触发更新部署上线。
